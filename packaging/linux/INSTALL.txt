Maily for Linux (x86_64)
========================

1. Required system packages (GTK 3 and WebKitGTK 4.1, GObject introspection 2.0):

   Debian 13, Ubuntu 24.04 or newer:
     sudo apt install gir1.2-webkit2-4.1 libgirepository-2.0-0 libcairo-gobject2
   Fedora 40 or newer:
     sudo dnf install webkit2gtk4.1 gtk3 cairo-gobject gobject-introspection
   Arch Linux:
     sudo pacman -S webkit2gtk-4.1 gtk3 gobject-introspection-runtime

   The binary needs glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40).

2. Run Maily from this folder:

     ./maily

   Keep the folder together: "maily" needs the "_internal" folder next to it.
   Move the whole folder where you want first, for example ~/.local/opt/Maily.

3. Optional: add Maily to your applications menu (run from this folder):

     mkdir -p ~/.local/bin ~/.local/share/applications ~/.local/share/icons/hicolor/512x512/apps
     ln -sf "$PWD/maily" ~/.local/bin/maily
     cp maily.png ~/.local/share/icons/hicolor/512x512/apps/maily.png
     cp maily.desktop ~/.local/share/applications/maily.desktop

   The menu entry runs "maily" from ~/.local/bin. If your menu does not find it,
   replace "Exec=maily" in ~/.local/share/applications/maily.desktop with the
   full path of the maily file.

Your data lives in ~/.local/share/maily (or $XDG_DATA_HOME/maily). Removing this
folder of the app does not remove your data.

The binary is not signed. Check the download first:
  sha256sum -c Maily-X.Y.Z-linux-x64.tar.gz.sha256

Help, source and other ways to run Maily: https://github.com/ThanaelFontaine/Maily
