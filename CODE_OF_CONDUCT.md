# Code of conduct

Maily adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. By taking part in this project (issues, pull requests, discussions), you agree to follow it.

In short: be respectful and welcoming, assume good faith, accept constructive criticism, and focus on what is best for the people using and building Maily. Harassment, insults, personal attacks and publishing other people's private information are not tolerated.

## Reporting

If you witness or experience unacceptable behavior, contact the maintainer privately through GitHub (a private security advisory works too, see [SECURITY.md](SECURITY.md)), or by the contact details on the maintainer's GitHub profile. Reports are handled confidentially. The enforcement guidelines of the Contributor Covenant apply.
